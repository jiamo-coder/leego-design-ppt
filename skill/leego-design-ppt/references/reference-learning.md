# Reference collection and promotion

Collect external examples only when that research is requested. Diagnose the current Skill first; a large image folder is not a design knowledge base. Start with a manageable, diverse sample (30–50 candidates is a future research target, not a quota or completed library).

## Candidate record

Record stable id, platform, original page URL, creator, observed date, page purpose, scenario, style family, grid/hierarchy, palette, typography, density, reusable rule, exclusions, asset rights, evidence and review status. Keep likes/saves/comments separate with observation time and access status. Unknown counts are null, never zero or an invented rank. A thumbnail proxy is not the original author page or a verified platform statistic.

Use `data/reference-cases.json` for reviewed public records. It starts empty intentionally. Source image collection is optional; keep licensed assets or reference links, not copied paid template packs. Do not access private material, bypass platform restrictions or package client source decks. User-provided historical discussions are strategy proposals until independently verified; do not describe their references as freshly inspected.

## Two independent assessments

Platform popularity helps discover candidates; it does not establish professional quality. Evaluate design quality through evidence clarity, hierarchy, readability, brand fit, editing feasibility and accessibility. A social cover can be effective marketing yet unsuitable for a shareholder report.

Promotion requires a verified source (or an explicitly original synthetic case), a concrete extracted principle, applicable conditions, counterexamples, rights notes and a same-content test. States: candidate → inspected → rule-proposed → benchmarked → approved/rejected. Never promote by popularity alone. Record reviewer/date and failed cases; omit unsupported scores rather than manufacture precision.

A reusable lesson states: “When [content and audience conditions], use [composition] because [observable benefit]; avoid when [countercondition].” Copying appearance without those conditions is not a learned rule.
