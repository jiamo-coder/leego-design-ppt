# Presenter notes and sources

Speaker notes should help delivery without leaking production instructions.

For each slide, store:

- purpose;
- 2-4 talking points;
- transition to the next slide;
- timing only when requested;
- citations and asset attributions.

Use a machine-readable source block when external sources are used:

```xml
<sources>
- https://example.com/source-page
</sources>
```

Keep a small human-readable source label on the slide when the audience needs it. Never expose internal file paths, search IDs, tool tokens, or uncited copied claims.
