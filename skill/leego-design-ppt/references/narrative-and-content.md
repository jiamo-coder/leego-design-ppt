# Narrative and content optimization

## Communication job

Write one sentence before outlining:

`By the end, [audience] should [understand/believe/choose/approve/do] [outcome] because [central takeaway].`

For neutral or exploratory decks, define the questions the audience must be able to answer.

## Evidence-safe content model

Classify every statement:

- `verified`: supported by supplied material or a cited source;
- `inference`: a clearly labeled synthesis from verified material;
- `proposal`: recommended direction, action, or wording;
- `example`: illustrative and visibly marked as non-production data.

Never convert a proposal or example into a factual claim.

## Slide logic

Each slide requires:

- one narrative job;
- one audience-facing takeaway title;
- the minimum evidence needed to support it;
- one implication or transition.

Useful arcs include context -> stakes -> evidence -> implication -> action; question -> analysis -> answer; current state -> change -> future state; or problem -> causes -> recommendation.

## Editing rules

- Remove duplicate claims and repeated summaries.
- Replace topic titles such as “Market Analysis” with a specific takeaway.
- Prefer concrete verbs and audience language over abstract noun clusters.
- Keep production notes and model instructions out of visible copy.
- End on a decision, action, synthesis, or useful question, not a generic thanks page.
