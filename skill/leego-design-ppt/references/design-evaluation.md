# Same-content evaluation

Compare a frozen baseline and proposed decision system on identical brief, facts, assets and output formats. Hold font availability and canvas size constant. Keep the old files intact. Compare the changed decisions and actual rendered pages, not two unrelated showcases.

## Hard gates

- No fabricated figures, quotes, customers or unsupported causal claims.
- No clipping, image distortion, dropped content or missing source labels.
- Real PPTX editability where promised; working H5 navigation/reading mode.
- Unknown data remains distinct from zero; fonts and page counts verified for PDF.

A hard-gate failure blocks promotion regardless of aesthetic score.

## Review dimensions

For each, record a concrete before/after observation and reviewer; optional 1–5 ratings are human judgments, not automated aesthetic proof.

1. Narrative: audience understands the conclusion and requested decision.
2. Hierarchy: one primary claim, evidence easy to locate, appropriate density.
3. Composition: alignment, whitespace, image intent and rhythm support meaning.
4. Data: correct representation, scale, unit, period, sources and missingness.
5. Consistency: stable brand, type roles and semantics across the deck.
6. Delivery: editable objects, H5 behavior and requested export quality.

Current repository tests cover ten design-decision scenarios plus portable export regression. They verify selection behavior, constraints and file properties, not that ten complete decks were visually accepted. Keep real output review separate. Only a reviewed reusable improvement enters shared rules; private project preferences remain local.
