# Typography and layout system

## Default canvas and grid

- Presentation canvas: 1280 x 720, 16:9.
- Safe frame: 72 px horizontal, 56-64 px vertical.
- Base spacing unit: 8 px.
- Default columns: 12 with 24-32 px gutters.
- Keep equal left/right margins unless the composition intentionally breaks the grid.

## Type scale

- Deck title: 54-80 pt.
- Slide title: 36-52 pt; one line by default.
- Section title: 42-64 pt.
- Subhead/callout: 24-30 pt.
- Body: 17-22 pt.
- Labels/source notes: 10-13 pt.

Use a Chinese/Latin system sans stack unless the brand specifies a licensed font. Use monospaced type only for short metadata or numeric labels.

## Fit rules

- Never permit a single-line title or banner to wrap unexpectedly.
- Flag any line containing only one CJK character or one short token unless intentionally designed.
- Shorten text or change layout before reducing type.
- Do not fill more than roughly two-thirds of a slide with body copy.
- Use line lengths of 16-28 CJK characters or 45-75 Latin characters for paragraph readability.

## Visual character

The default `purple-tech` theme uses flat color, crisp lines, strong type, and restrained geometry. Avoid ornamental gradients, excessive corner rounding, glass effects, heavy shadows, and generic UI-card grids.

Use no more than one dominant accent per page. Treat whitespace as structure, not an empty area to fill.
